## 🔎 프로젝트 소개
스니펫(Snippet)'은 재사용 가능한 소스 코드, 텍스트의 작은 조각을 의미합니다
Code.Snippet은 개발 과정에서 작성한 트러블슈팅, 코드 메모, 학습 내용을 기록하고 공유할 수 있는 짧은 글 중심의 개발 노트 SNS입니다
